# 회사 내부 고객명단 관리 앱

회사 사람들끼리 고객명단, 듣는 수업, 입금 전/후/부분입금 상태를 관리하는 MVP입니다.

## 포함 기능

- 회사 비밀번호 로그인
- 고객 추가/삭제
- 고객명, 연락처, 수업명, 담당자, 메모 관리
- 입금 상태: 입금 전 / 부분 입금 / 입금 후
- 통화/상담 상태 색상 관리
  - 통화전: 흰색
  - 통화후 입금대기중: 노랑색
  - 수업 듣지 않음: 빨간색
  - 부재중: 파랑색
- 수업별 필터
- 입금 상태별 필터
- 검색
- 입금 요약 대시보드
- 브라우저 localStorage 저장

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 표시되는 주소로 접속합니다.

## 초기 비밀번호

```text

```

## 검증 완료

